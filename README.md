# 《心靈病房》敘事電影讀書會．心得競賽網站

一個網站包含：電影導讀、寫作主題與競賽辦法、線上投稿、匿名作品集（即時排行榜與票數）、一次性投票、承辦人登入後台（投稿／投票名單、公開作品、幸運參與獎抽獎）。

- `site/`：網站本體（放到 GitHub Pages）
- `backend/Code.gs`：資料後端（貼到 Google 試算表的 Apps Script）

資料（名單、投稿、票數、抽獎結果）全部存在您的 Google 試算表。

## 一、建立資料後端（約 10 分鐘）

1. 開一個新的 Google 試算表 →「擴充功能 → Apps Script」→ 刪掉預設內容，貼上 `backend/Code.gs`，儲存。
2. 回到試算表重新整理 → 選單「敘事競賽 → 1. 初始化」→ 依提示授權。
3. 把 `名單_匯入用.xlsx` 第 2 列以下貼到「名單」工作表；11/11 看完電影後，把參加者的「11/11 參加觀影」標為「是」。
4. 選單「敘事競賽 → 設定承辦人帳號密碼」。
5. Apps Script 右上「部署 → 新增部署作業」→ 類型「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→ 部署 → 複製網址（結尾是 `/exec`）。

## 二、放上 GitHub Pages

1. 打開 `site/config.js`，把剛才的網址貼進引號：`window.WIT_API_URL = "https://script.google.com/macros/s/……/exec";`
2. 在 GitHub 建立新的 repository（例如 `wit`），把 `site/` 裡的所有檔案上傳到根目錄。
3. repository 的「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/ (root)` → Save。
4. 約 1 分鐘後，網址會是 `https://您的帳號.github.io/wit/`。

## 承辦人後台

網站最下方「承辦人登入」，輸入帳密後可以：
- 看投稿名單、勾選作品「公開」（隨機編號，立刻出現在作品集）
- 看未投稿（Seminar 提問名單）、已投票／未投票名單、未計入的投票
- 看含作者的排行榜
- 11/18 13:00 起抽出幸運參與獎 2 名

## 注意

- 修改 `Code.gs` 後要到「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，網址不變。
- 每人限投稿一篇，送出後不能修改；每人限投票一次。
- 人事號／姓名只用來確認資格與防止重複；知道別人人事號的人可以冒名，系統無法完全防止。
- 匿名：投票紀錄只記「誰投過」，票數另外累計，不保存「誰投給誰」。
